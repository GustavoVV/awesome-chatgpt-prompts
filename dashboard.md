# Dashboard de prompts (prioridades y categorías)

Este dashboard resume qué prompts **siguen valiendo la pena** por utilidad práctica y los ordena por **prioridad** dentro de cada categoría. La prioridad se basa en: (1) reutilización frecuente, (2) valor práctico inmediato, (3) claridad del prompt, y (4) bajo riesgo de mal uso.

> **Leyenda de prioridad**
> - **Alta**: alto valor general y uso frecuente.
> - **Media**: útil en contextos específicos o con ajustes.
> - **Baja / Archivar**: poco diferencial, potencialmente problemático, o redundante.

## Notas de alcance
- Los prompts marcados como **Baja / Archivar** no se recomiendan como “default” por baja utilidad general, alto riesgo o redundancia. Si se desean mantener, conviene reescribirlos con guardrails y expectativas claras.
- Este dashboard no elimina prompts del repositorio; solo prioriza el uso para un acceso rápido.
